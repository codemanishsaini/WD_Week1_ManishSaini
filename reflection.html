My HTML Learning Reflection

What I Learned

I learned the basic structure of an HTML document and how to create webpages using different HTML elements. I learned about headings, paragraphs, text formatting, links, images, lists, tables, and forms. I also understood the importance of semantic HTML tags such as header, nav, main, section, article, and footer.

Most Challenging Topic

The most challenging topic for me was HTML forms, especially understanding the name and value attributes. With practice, I learned how they help identify form fields and their values.

My Favorite Concepts

I enjoyed creating tables, adding hyperlinks, and building a student registration form. These concepts helped me understand how webpages organize and collect information.

How HTML Will Help Me

HTML is the foundation of web development. It will help me learn CSS, JavaScript, React, and other technologies. I want to use these skills to build useful websites and become a software developer.
